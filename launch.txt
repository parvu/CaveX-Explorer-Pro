# --- 5a. NORMAL path: /cmd_vel -> cmd_vel_to_ardupilot.py -> ArduPilot GUIDED+armed
# -> /ap/twist/filtered -> track_cmd_vel_bridge.py -> gz_bridge -> track drive.
# ArduPilot needs a few seconds for EKF/prearm checks to settle before arming
# succeeds (first attempt may report result=False — normal, retries automatically).
# IMPORTANT: use a single persistent `-r N` publisher, NOT a shell loop spawning a
# new `ros2 topic pub --once` process every iteration -- each spawn needs real DDS
# discovery time that can exceed a short sleep, so a spawn-loop effectively never
# actually delivers commands (confirmed the hard way).

DRIVEPID=$!
sleep 15
